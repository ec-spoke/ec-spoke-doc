    product_var_mst_val_combs テーブル定義

    概要

    商品バリエーション（SKU）とバリエーションマスター値の多対多関係を管理する中間テーブル。1つのSKUが複数のバリエーション値（サイズS、色赤など）を組み合わせて構成される場合に使用する。

    テーブル情報

    項目 値
    テーブル名 product_var_mst_val_combs
    エンジン InnoDB
    文字セット utf8mb4
    照合順序 utf8mb4_unicode_ci
    コメント 商品バリエーション-バリエーションマスター値組み合わせ

    カラム定義

    カラム名 型 NULL デフォルト キー 説明
    product_var_id BIGINT UNSIGNED NOT NULL - PK,FK 商品バリエーションID（product_vars.id）
    product_var_mst_vals_id BIGINT UNSIGNED NOT NULL - PK,FK バリエーションマスター値ID（product_var_mst_vals.id）
    created_at TIMESTAMP NULL NULL - 作成日時
    updated_at TIMESTAMP NULL NULL - 更新日時

    インデックス

    種別 名称 対象カラム 説明
    PRIMARY KEY pk_product_var_mst_val_combs product_var_id, product_var_mst_vals_id 複合主キー
    INDEX idx_product_var_mst_vals product_var_mst_vals_id バリエーションマスター値別の検索

    外部キー制約

    名称 対象カラム 参照先 ON DELETE ON UPDATE 説明
    fk_product_var_mst_val_combs_var product_var_id product_vars(id) CASCADE RESTRICT 商品バリエーション削除時に関連レコードも削除
    fk_product_var_mst_val_combs_val product_var_mst_vals_id product_var_mst_vals(id) CASCADE RESTRICT バリエーションマスター値削除時に関連レコードも削除

    リレーション

    関連先テーブル 関連タイプ 外部キー 参照先 ON DELETE ON UPDATE 説明
    product_vars N:1 product_var_id id CASCADE RESTRICT 組み合わせは1つの商品バリエーションに属する
    product_var_mst_vals N:1 product_var_mst_vals_id id CASCADE RESTRICT 組み合わせは1つのバリエーションマスター値に属する

    データ例

    Tシャツ商品の場合

    product_vars（SKU）

    id product_id product_code price stock
    1 100 TSH-S-RED 2500 50
    2 100 TSH-M-BLUE 2500 30

    product_var_mst_val_combs（SKUとバリエーション値の組み合わせ）

    product_var_id product_var_mst_vals_id 説明
    1 1 (サイズ-S) SKU#1の1つ目の軸
    1 5 (色-赤) SKU#1の2つ目の軸
    2 2 (サイズ-M) SKU#2の1つ目の軸
    2 6 (色-青) SKU#2の2つ目の軸

    product_var_mst_vals（バリエーション値マスター）

    id product_var_mst_id variation_value
    1 1 (サイズ) S
    2 1 (サイズ) M
    5 2 (色) 赤
    6 2 (色) 青
    10 3 (素材) コットン

    3軸バリエーションの例（Tシャツ：サイズ×色×素材）

    product_vars（SKU）

    id product_id product_code price stock
    3 100 TSH-S-RED-COTTON 2500 20

    product_var_mst_val_combs（3軸の組み合わせ）

    product_var_id product_var_mst_vals_id 説明
    3 1 (サイズ-S) 1つ目の軸
    3 5 (色-赤) 2つ目の軸
    3 10 (素材-コットン) 3つ目の軸

    備考・注意事項

    多軸バリエーションの表現

    • 1軸: サイズのみ（S、M、L）
    • 2軸: サイズ×色（S-赤、M-青など）
    • 3軸以上: サイズ×色×素材など、無制限に対応

    商品詳細表示での活用

    • 商品詳細ページ: このテーブルから逆引きしてバリエーション軸を取得
    • データ整合性: 真実の情報源から取得することで、実際のSKUと表示が一致
    • 実装例: 商品のバリエーション選択肢は、実際に存在するSKUから動的に生成

    軸数制約

    • 軸数一致: 商品で選択した軸数と、SKUの軸数は一致する必要がある
    • 制約例:
    • 2軸選択商品（サイズ×色）→ 2軸のSKUのみ作成可能
    • 3軸選択商品（サイズ×色×素材）→ 3軸のSKUのみ作成可能
    • 実装: SKU作成時に、選択された軸数と一致するかバリデーション

    データ整合性

    • UNIQUE制約: 同じSKUに同じバリエーション値を重複登録不可
    • 外部キー制約: 存在しないSKUやバリエーション値は登録不可
    • CASCADE削除: SKUまたはバリエーション値が削除されると、関連する組み合わせも自動削除

    クエリ例

    -- Tシャツ（商品ID: 100）の全SKUとそのバリエーション値を取得
SELECT
    pv.id as sku_id,
    pv.product_code,
    pv.price,
    pvm.variation_name,
    pvmv.variation_value
FROM product_vars pv
JOIN product_var_mst_val_combs pvmvc ON pv.id = pvmvc.product_var_id
JOIN product_var_mst_vals pvmv ON pvmvc.product_var_mst_vals_id = pvmv.id
JOIN product_var_msts pvm ON pvmv.product_var_mst_id = pvm.id
WHERE pv.product_id = 100
ORDER BY pv.id, pvm.sort_order, pvmv.sort_order;

-- 特定の組み合わせ（サイズS × 色赤）のSKUを検索
SELECT pv.*
FROM product_vars pv
WHERE pv.id IN (
    SELECT pvmvc1.product_var_id
    FROM product_var_mst_val_combs pvmvc1
    JOIN product_var_mst_vals pvmv1 ON pvmvc1.product_var_mst_vals_id = pvmv1.id
    JOIN product_var_msts pvm1 ON pvmv1.product_var_mst_id = pvm1.id
    WHERE pvm1.backend_name = 'size' AND pvmv1.variation_value = 'S'
)
AND pv.id IN (
    SELECT pvmvc2.product_var_id
    FROM product_var_mst_val_combs pvmvc2
    JOIN product_var_mst_vals pvmv2 ON pvmvc2.product_var_mst_vals_id = pvmv2.id
    JOIN product_var_msts pvm2 ON pvmv2.product_var_mst_id = pvm2.id
    WHERE pvm2.backend_name = 'color' AND pvmv2.variation_value = '赤'
);

    UNIQUE制約による整合性保証

    制約の目的

    同じSKUに対して、同じバリエーションマスターから複数の値が登録されることを防止。

    実装方法

    MySQLでは外部テーブル経由のUNIQUE制約を直接設定できないため、以下の方法で実装：

    方法1: 複合UNIQUE制約（推奨）

    -- product_var_mst_valsテーブルにproduct_var_mst_idを非正規化
ALTER TABLE product_var_mst_val_combs
ADD COLUMN product_var_mst_id BIGINT UNSIGNED NOT NULL AFTER product_var_mst_vals_id,
ADD CONSTRAINT fk_product_var_mst_val_combs_mst
    FOREIGN KEY (product_var_mst_id) REFERENCES product_var_msts(id) ON DELETE RESTRICT ON UPDATE RESTRICT,
ADD UNIQUE KEY uk_var_mst_combination (product_var_id, product_var_mst_id);

    メリット: - DB層で整合性を保証 - パフォーマンス向上（JOINレス）

    デメリット: - 非正規化（product_var_mst_idの重複保持）

    方法2: アプリケーション層バリデーション

    // SKU保存時のバリデーション例
public function validateVariationCombination(ProductVar $productVar, array $varMstValIds): void
{
    $masterIds = ProductVarMstVal::whereIn('id', $varMstValIds)
        ->pluck('product_var_mst_id')
        ->toArray();

    if (count($masterIds) !== count(array_unique($masterIds))) {
        throw new ValidationException('同じバリエーションマスターから複数の値は選択できません');
    }
}

    メリット: - 正規化を維持 - 柔軟なエラーメッセージ

    デメリット: - DB層での保証がない - 複数リクエストの同時処理でレースコンディションのリスク

    方法3: トリガー（非推奨）

    -- INSERTトリガーで検証
DELIMITER $$
CREATE TRIGGER check_duplicate_master BEFORE INSERT ON product_var_mst_val_combs
FOR EACH ROW
BEGIN
    DECLARE mst_count INT;

    SELECT COUNT(DISTINCT pvmv.product_var_mst_id)
    INTO mst_count
    FROM product_var_mst_val_combs pvmvc
    JOIN product_var_mst_vals pvmv ON pvmvc.product_var_mst_vals_id = pvmv.id
    WHERE pvmvc.product_var_id = NEW.product_var_id;

    IF mst_count >= (
        SELECT COUNT(*) FROM product_var_mst_rel WHERE product_id = (
            SELECT product_id FROM product_vars WHERE id = NEW.product_var_id
        )
    ) THEN
        SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '同じマスターから複数の値は登録できません';
    END IF;
END$$
DELIMITER ;

    メリット: - DB層で保証 - 正規化を維持

    デメリット: - 複雑でメンテナンスが困難 - パフォーマンス低下

    推奨実装

    Phase 1（現在）: 方法2（アプリケーション層バリデーション）で実装

    Phase 2（将来）: 方法1（非正規化 + UNIQUE制約）への移行を検討

    Eloquentモデルでの使用例

    // ProductVarモデル
class ProductVar extends Model
{
    public function combinations(): HasMany
    {
        return $this->hasMany(ProductVarMstValComb::class);
    }

    public function varMstVals(): BelongsToMany
    {
        return $this->belongsToMany(ProductVarMstVal::class, 'product_var_mst_val_combs');
    }
}

// ProductVarMstValモデル
class ProductVarMstVal extends Model
{
    public function productVars(): BelongsToMany
    {
        return $this->belongsToMany(ProductVar::class, 'product_var_mst_val_combs');
    }
}

// 使用例
$productVar = ProductVar::with('varMstVals.varMst')->find(1);
foreach ($productVar->varMstVals as $val) {
    echo $val->varMst->variation_name . ': ' . $val->variation_value . "\n";
}
